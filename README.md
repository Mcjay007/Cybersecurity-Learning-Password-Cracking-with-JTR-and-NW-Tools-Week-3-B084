## 📌 Overview

This repository documents my learning journey in Cybersecurity, focusing on password cracking techniques, password security, ethical hacking, and penetration testing.

It explores how password attacks work, how security professionals assess password vulnerabilities, and how individuals and organizations can protect their digital identities.

## 🎯 Objectives

- Understand password cracking techniques.
- Learn password hashing and salting.
- Explore brute-force and dictionary attacks.
- Understand online and offline password attacks.
- Practise password auditing using cybersecurity tools.
- Learn how to identify weak passwords.
- Understand password protection mechanisms.
